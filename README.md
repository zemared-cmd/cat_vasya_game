# cat_vasya_game

Ролевая игра с пошаговой боевкой от кота Василия.(Семёна Шулепова)

Модуль 1.
1. Содержит абстрактный класс Unit с 6 характеристиками
2. Абстрактные методы: calculate_max_health, calculate_damage, `calculate_defense
3. Класс Monster с реализацией формул

Модуль 2.

1. Класс Character с поддержкой классов: warrior, mage, hunter
2. Формулы для урона, защиты и маны

Модуль 3.
1. Абстрактный класс Spell с методом cast
2. Конкретные заклинания: Fireball, IceLance, LightningBolt
3. Система маны и управления заклинаниями в Unit

Тесты - main.py
